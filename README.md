
# PixelGallery — Image Gallery

## Project Overview
PixelGallery is a responsive, interactive image gallery developed as part of the CodeAlpha Image Gallery project.

It organizes images into categories and allows users to view images in an enlarged lightbox.

## Features
- Responsive image gallery layout
- Category filtering: Nature, Architecture, and Technology
- Interactive lightbox for enlarged image viewing
- Next and previous image navigation
- Keyboard navigation
- Image hover effects
- Lazy loading for improved performance
- Image error handling and fallback support

## Technologies Used
- HTML5
- CSS3
- JavaScript
